# API каталога роботов-исследователей

Учебный проект на FastAPI, реализующий динамические маршруты и фильтрацию данных.

## Эндпоинты
- `GET /` — информация о сервисе[cite: 18].
- `GET /robots` — получение списка всех роботов (поддерживает фильтрацию по статусу с помощью параметра `?status=active`)[cite: 18, 19].
- `GET /robots/{robot_id}` — получение информации об одном роботе по его ID (с обработкой ошибки 404, если робот не найден)[cite: 18, 19].
